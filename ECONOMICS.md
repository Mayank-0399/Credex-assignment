### Database

* Supabase Free Tier
* Current cost: Free

### Backend APIs

* Next.js API Routes
* Hosted together with frontend on Vercel

### AI Costs

The project currently avoids direct LLM API usage for summaries and recommendations, which keeps operational costs close to zero.

---

## Why Lightweight Logic Was Used

The project intentionally uses deterministic audit logic and lightweight summaries because:

* API costs remain low
* responses are faster
* recommendations are easier to test
* financial outputs stay predictable
