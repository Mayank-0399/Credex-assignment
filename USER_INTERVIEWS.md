# User Interviews

## Overview

Since this project was built as an MVP, the interviews below are lightweight discovery conversations and observations based on discussions with students, developers, and small-team users who actively use AI tools.

The goal was to understand:

* how teams currently manage AI subscriptions
* whether people track AI spending carefully
* what problems exist with multiple AI tools

---

## Interview 1 — Student Developer

### Profile

* Solo developer
* Uses ChatGPT, Cursor, and GitHub Copilot

### Key Insight

The user mentioned that they subscribed to multiple AI tools over time but never compared whether they actually needed all paid plans simultaneously.

### Pain Points

* difficult to track monthly AI spending
* overlapping functionality between tools
* no simple way to benchmark pricing

---

## Interview 2 — Content Creator

### Profile

* Individual creator using AI writing tools

### Key Insight

The user preferred simple recommendations instead of complicated analytics dashboards.

### Pain Points

* subscription fatigue
* difficulty deciding which tools to keep
* limited visibility into annual spending totals

---

## Common Patterns Observed

Across interviews, the most common themes were:

* people rarely track AI spending carefully
* many users over-subscribe to tools
* pricing decisions are often based on trends instead of actual usage
* users prefer simple, actionable recommendations

---

## Product Direction Influenced By Interviews

These conversations influenced several product decisions:

* keeping the UI simple
* generating easy-to-understand summaries
* focusing on savings opportunities
* using explainable rule-based recommendations
* adding shareable audit reports
