# AI Spend Audit

A web app that helps startups analyze and optimize their AI tooling costs.

Users can input their AI subscriptions, discover overspending, and receive actionable recommendations for reducing monthly and annual spend.

## Tech Stack

- Next.js
- TypeScript
- TailwindCSS
- shadcn/ui
- Supabase
- OpenAI API
